Featured products

Built and working.

Featured product #1

Smart Arcade Rent Manager

An Android app that manages rent and utilities for a mall, built in Java with SQLite.

  • Tenant portal: tenants see what they owe and pay.
  • Landlord dashboard: PIN-protected view of every unit.
  • WhatsApp invoices: bills sent straight to tenants.
Featured product #2

Safe Response Uganda

A web application for managing and handling emergencies, built using JavaScript for its backend.

  • Realtime alerts: instant notifications about nearby emergencies.
  • Live location: quick real time emergency locator.
  • Incident mapping: incidents shown visually on the map.
